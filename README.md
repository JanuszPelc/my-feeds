<h2>University of Birmingham Researcher Measures Time Without External Clock Using Cold Atoms</h2>
<a name="story-25933"><img src="https://wsrv.nl/?url=https%3A%2F%2Findiandefencereview.com%2Fwp-content%2Fuploads%2F2026%2F06%2Fentropic-internal-time-vs-laboratory-time-across-varying-barrier-heightsphysical-review-research-1200x727.jpg&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>University of Birmingham physicist Professor Giovanni Barontini has created a miniature universe using approximately 24,000 ultracold atoms to demonstrate that the passage of time can emerge internally from system changes rather than relying on an external clock. Published in Physical Review Research, the experiment provides empirical evidence for theoretical physics concepts suggesting that time is not a fundamental property of the universe, but rather arises from relationships among its constituent particles.</p><p>The research isolates the atomic cloud using laser beams divided into observed and unobserved regions that undergo repeated expansion and contraction cycles analogous to cosmic events. By tracking entropy changes as atoms move between regions, the system establishes an internal "entropic time" that dictates an arrow of time and can be integrated into foundational quantum equations like the Schrödinger equation.</p>

<h2>TRM Labs Attributes Binance Crypto Theft to North Korea</h2>
<p>Blockchain analysis firm TRM Labs has attributed the theft of approximately $6.36 billion from Binance to TraderTraitor, a North Korea-based hacking group. The attacker drained funds across ten blockchains, mostly within a span of about 20 minutes, marking the largest cryptocurrency theft on record.</p><p>The breach involved a compromise of Binance's hot wallet signing infrastructure, triggering widespread industry precautions such as asset freezes across decentralized finance markets like Aave and Arbitrum. Investigators and security researchers are actively tracing the stolen funds as the crypto sector grapples with the fallout from the massive exploit.</p>

<h2>Anthropic Study Finds Experts Frequently Defer to AI Agents in Judgment Calls</h2>
<a name="story-25667"><img src="https://wsrv.nl/?url=https%3A%2F%2Fwww.anthropic.com%2F_next%2Fimage%3Furl%3Dhttps%253A%252F%252Fwww-cdn.anthropic.com%252Fimages%252F4zrzovbb%252Fwebsite%252Fea6b9bd3ca8b59f150d912a3855fc1beaf9e7792-1920x926.png%26w%3D3840%26q%3D75&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Anthropic researchers conducted a randomized controlled trial involving 50 professional analysts performing a causal inference task using Claude Code to examine whether human experts maintain independent judgment when working with AI agents. By secretly introducing a randomized preference into each agent's instructions across four analytical decisions, the study measured how often experts adopted the agent's preferred option.</p><p>The results showed that analysts followed their agents' leans 86% of the time, frequently repeating the agents' arguments in post-task surveys while believing their final recommendations were entirely their own. Although analysts using AI completed tasks faster and made fewer methodological errors than those working without it, the findings highlight potential risks of unintentional human deference to hidden or arbitrary AI preferences in critical fields like safety research.</p>
<p><small>Links: <a href="https://www.anthropic.com/research/agents-judgment-calls">anthropic.com</a> | <a href="https://news.ycombinator.com/item?id=50271917">hacker news</a></small></p>

<h2>AlpineBSD Operating System Combines NetBSD Kernel with Alpine Linux-Inspired Userspace</h2>
<a name="story-25677"><img src="https://wsrv.nl/?url=https%3A%2F%2Fwww.netbsd.org%2Fdocs%2Fpuffs%2Frump.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>AlpineBSD is a work-in-progress operating system that pairs the NetBSD kernel, libc, and essential platform-specific tools with a userspace inspired by Alpine Linux. The project aims to minimize the inclusion of AI-generated software, excluding large language model output entirely from its base system and main package repository.</p><p>While it utilizes the apk-tools package manager and BusyBox like Alpine Linux, AlpineBSD features a slightly more GNU-oriented userspace and currently relies on the s6 init system, with plans to add OpenRC support. Because it is built on the NetBSD kernel, the operating system currently lacks an official installer and has limited hardware support compared to Linux distributions.</p>

<h2>Phorion Discovers Persistent SSH Backdoor in Official Claude Code Extension</h2>
<a name="story-25960"><img src="https://wsrv.nl/?url=https%3A%2F%2Fcoinedition.com%2Fwp-content%2Fuploads%2F2026%2F07%2Fmagnific_alibaba-to-ban-claude-cod_74x4rjnJAL.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Phorion identified a supply-chain compromise affecting version 2.1.313 of the official Claude Code for VS Code extension distributed on the Cursor Marketplace. The malicious extension bundle executes an injected script upon loading that installs an attacker-controlled Ed25519 public key into authorized_keys, initiates a persistent reverse SSH tunnel, and transmits host reconnaissance data.</p><p>The cross-platform implant targets macOS, Linux, and Windows systems, though researchers identified several implementation flaws, including a macOS check failure that can disrupt inbound access if Remote Login is disabled. Following the discovery, marketplaces removed the malicious build, prompting recommendations for organizations to audit environments for the affected version and initiate incident response procedures.</p>

<h2>Martin Fowler Publishes Essay on Uncanny Valley of LLM Voice</h2>
<a name="story-25880"><img src="https://wsrv.nl/?url=https%3A%2F%2Fstatic-cdn.cars24.com%2Fprod%2Fcms%2F2026%2F01%2F29%2F0066df65-477d-4821-a782-2ab1c46a8c2eIMG_20260129_145754_289.jpg&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Martin Fowler examines the phenomenon of "LLM Voice," a distinct stylistic tone found in prose generated by large language models that triggers a textual uncanny valley and erodes reader trust. He argues that this artificial prose style is instantly recognizable to human readers, rendering automated detection tools largely unnecessary.</p><p>While advising authors to avoid using LLMs for drafting or rephrasing to preserve their authentic voice, Fowler acknowledges necessary exceptions, such as assisting individuals with Parkinson's disease or aiding non-native speakers with translation. He emphasizes that writing is fundamentally a tool for human thinking, warning that delegating prose generation to AI risks outsourcing comprehension itself.</p>

## Worth knowing

The feeds are aggregated by an agentic pipeline, which rewrites every title and summary in
a plain, measured tone. Lead images are chosen by vision models. Nothing is reviewed by
hand, so check anything that matters against the linked sources.

Feed links rarely change, but if a feed in your reader goes quiet for a few days, come back
here and resubscribe.
