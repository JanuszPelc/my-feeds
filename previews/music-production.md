<h2>Expetri Experimental Software Synthesizer Released in AU and VST3 Formats</h2>
<p>Expetri has released its self-titled experimental software synthesizer for macOS in VST3 and AU formats. The plugin approaches sound design through the metaphor of a chemistry experiment, allowing users to grow sound cells in a virtual petri dish rather than manually adjusting traditional synthesis parameters.</p><p>The interface lets users interact with sound cells by stirring the dish, adding or removing elements with a pipette, and applying effect liquids from flasks. The software is available in both a free tier and a full version priced at an introductory $9.99, with rare cell generation reserved for the paid release.</p>

<h2>Cineol-X 224 Free Lexicon Reverb Plugin Released</h2>
<p>Cineol-X 224 is a free reverb plugin for macOS and Windows that emulates classic hardware units using data derived from original Lexicon 224 v4.4 and 224 XL v8.21 firmware. It includes 28 programs spanning the six algorithms of the original 224 and 22 algorithms from the 224XL, featuring an automatic engine selection function.</p><p>Operation requires users to supply their own original Lexicon ROM files upon first use. The VST3 plugin is available for download via the project's GitHub releases page.</p>

<h2>M-Vave FM-1 Pocket Synthesizer Emerges as Custom Firmware Platform</h2>
<p>The M-Vave FM-1 is an inexpensive pocket frequency-modulation synthesizer that has evolved into a popular platform for community-developed custom firmware. Originally released as a budget device inspired by the Yamaha DX7, the hardware sparked reverse-engineering efforts that led to user-created software expanding its capabilities far beyond its stock configuration.</p><p>In response to the community trend, manufacturer M-Vave launched FM1 Open, an open-source development package featuring a browser-based workbench, software development kit, and updated firmware options. Community developers have since ported a wide variety of alternate packages to the device, transforming the pocket synthesizer into a multi-engine groovebox, chiptune workstation, and even a platform capable of running Doom.</p>

<h2>AudioBrain Releases ChimeBrain Physically Modeled Wind-Chime Instrument for macOS</h2>
<p>AudioBrain has released ChimeBrain, a physically modeled wind-chime instrument designed for macOS. Instead of relying on prerecorded samples, the software calculates the vibrations of suspended metal bars in real time to generate sound for music production, scoring, and sound design.</p><p>The instrument features up to 36 individually configurable metal bars with adjustable dimensions, materials, and pitch registers, alongside MIDI performance options, sweep and shake gestures, and direct on-screen interaction. It also includes five virtual microphone models and optional room acoustics, with version 1.0.2 disabling room reverb by default on new instances to reduce CPU usage. ChimeBrain is available as a universal AU, VST3, and standalone plugin priced at $19.</p>

<h2>Wide Blue Sound Updates Humanizer Pro to Version 1.0.6</h2>
<p>Wide Blue Sound has released version 1.0.6 of Humanizer Pro, a MIDI effect plug-in designed to introduce realistic timing and velocity variations to digital tracks. Unlike standard humanizers that apply basic random adjustments, the plug-in models how human musicians naturally fluctuate and self-correct during a performance.</p><p>The latest update introduces experimental support for Windows on Arm systems. Priced at an MSRP of $69, the software is compatible with macOS and Windows in VST3, AU, and AAX formats, and includes a dedicated Max for Live device.</p>

<h2>OBS Studio 33.0.0 Released with Updated Browser Engine and Plugin Overhaul</h2>
<p>OBS Studio 33.0.0 is now available, featuring a major upgrade to the underlying Chromium Embedded Framework from version 127 to 150 and a complete restructuring of plugin loading directories. The release also enables NVENC hardware encoding on Arm64 platforms, integrates updated NVIDIA Broadcast SDKs, and refines preview source snapping behaviors.</p><p>Developer-focused updates include higher minimum toolchain requirements such as Visual Studio 2026 and Windows SDK 26100, alongside the removal of support for Ubuntu 24.04, Qt versions 6.4 through 6.9, and FFmpeg 6.x and 7.x. The update additionally resolves multiple stability issues, including platform-specific crashes on macOS and Linux, and improves hybrid MP4 and MOV file splitting.</p>
