<h2>Sam Altman Discusses AI Vulnerabilities, Agent Teams, and Compute Scaling</h2>
<a name="story-25803"><img src="https://wsrv.nl/?url=https%3A%2F%2Fgizmodo.com%2Fapp%2Fuploads%2F2026%2F02%2Fsam-altman-openAI-1280x853.jpg&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>In an interview with Stripe co-founder John Collison on Cheeky Pint, OpenAI CEO Sam Altman discusses how AI models are uncovering critical PHP vulnerabilities, the role of test-time compute in enabling agent teams, and internal experiments tackling complex mathematical problems like Navier-Stokes. Altman also addresses the safety challenges of sandboxing superhuman models and the architectural shifts required as personal agents transform software development.</p><p>Altman reflects on the rapid pace of AI adoption, comparing the current creative explosion among young users to the early days of the internet. <h2>Deepgram Acquires Daily to Expand Voice AI Infrastructure</h2>
<a name="story-25805"><img src="https://wsrv.nl/?url=https%3A%2F%2Fbsmromhjxdnndenlrpgx.supabase.co%2Fstorage%2Fv1%2Fobject%2Fpublic%2Fentity-images%2Fposts%2F1016146.jpg&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Deepgram is acquiring Daily, the creator and maintainer of the open-source voice AI and real-time communication framework Pipecat. Financial terms of the transaction were not disclosed, and the companies plan to maintain Pipecat as an open-source project under an independent foundation.</p><p>Pipecat handles voice and video streams while integrating speech-to-text, text-to-speech, and large language models to minimize latency in conversational applications. Concurrently, Deepgram and the Pipecat team are introducing the Real-Time Context Standard, an open protocol intended to manage metadata, audio cues, and model instructions for voice agents.</p>

<h2>Claude Code Background Agent Summaries Consuming 20 Percent of Tokens Addressed by Bun Preload</h2>
<a name="story-25785"><img src="https://wsrv.nl/?url=https%3A%2F%2Fblogin.madewithlove.com%2Fuploaded%2F50068d2527bc62e18817c%2Fdisplay%2Fscreenshot_2026-04-14_at_16.26.37.png%3Fgt%3Dca9197d22ec4cb046ca1b4bd88870be97322e423&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Claude Code periodically sends the full transcripts of background agents to their respective models every 30 seconds to generate brief status descriptions, a process that accounts for 15 to 20 percent of total token consumption. This background activity occurs without user configuration options to disable it, impacting rate-limit headroom primarily through automated model requests that do not contribute to the main conversation.</p><p>To eliminate this overhead, developers have created a Bun preload script that intercepts and suppresses the specific timers responsible for triggering the summary requests. Testing across multiple versions indicates that disabling the feature successfully eliminates these requests while maintaining normal operation for background agents and subagents.</p>

<h2>Qwenputer Embeds RISC-V CPU into Qwen 3.5 Weights</h2>
<a name="story-25780"><img src="https://wsrv.nl/?url=https%3A%2F%2Fdivagr.com%2Fqwenputer%2Fdemo.gif&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Qwenputer is an experimental model based on Qwen 3.5 4B that embeds a 32-bit RISC-V CPU directly into its weights. By using Gated DeltaNet (GDN) layers as exact, addressable RAM, the CPU executes arithmetic, C, and MicroPython code during forward passes without external runtimes or tool calls.</p><p>The implementation uses one-hot key encoding for memory access and has achieved 100% accuracy on specific long-integer arithmetic benchmarks. An experimental filesystem also allows the model to store and retrieve text data via the DeltaNet state, providing persistent memory across conversation sessions.</p>
<p><small>Links: <a href="https://divagr.com/blog/qwenputer">divagr.com</a> | <a href="https://github.com/divagr18/qwenputer">source</a> | <a href="https://news.ycombinator.com/item?id=50282838">hacker news</a></small></p>

<h2>Artificial Analysis Releases Intelligence Index v5</h2>
<a name="story-25730"><img src="https://wsrv.nl/?url=https%3A%2F%2Fcdn.sanity.io%2Fimages%2F6vfeftx9%2Farticles%2F44b792b382975135ff1db34ca74a2502eb767158-2152x1016.png%3Fw%3D1200%26auto%3Dformat&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Version 5 of the Artificial Analysis Intelligence Index introduces two new benchmarks, FrontierCode 2.0 and Terminal-Bench-Science, and upgrades HLE-Diamond, AA-Omniscience v1.1, and CritPt v2. This update is the first to build 60% of the index using private datasets. The release also includes the Artificial Analysis Progress Index v1, designed to track model capability on a continuous scale over time.</p><p>Claude Opus 5.5 leads the index with a score of 58, ahead of OpenAI's GPT-6 Astra and GPT-6.1 Sol. The data indicates the gap between proprietary and open-weights models has widened from 3 points to 12 points. Furthermore, cost per task among the top 10 models varies by more than 13x.</p>

<h2>Google Announces Gemini 4 Carbon</h2>
<a name="story-25716"><img src="https://wsrv.nl/?url=https%3A%2F%2Fstorage.googleapis.com%2Fgweb-uniblog-publish-prod%2Fimages%2Fgemini_4_carbon_exploitgym.width-1200.format-webp.webp&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Google has introduced Gemini 4 Carbon, a frontier model designed for advanced cybersecurity and long-horizon engineering tasks. The model ranks first on the Artificial Analysis Intelligence Index (v5.0) and demonstrates high performance in vulnerability detection, exploitation, and remediation across benchmarks such as SEC-bench Pro, ExploitGym, and CWE-bench.</p><p>The model is built to support sustained agentic workflows and features improvements in model alignment, output honesty, and resistance to prompt injection. Google is currently rolling out access to a subset of cyber defenders and trusted partners through the Fairwind Program ahead of a wider release.</p>
