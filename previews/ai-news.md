This move follows reports of high net revenue retention for Anthropic and is intended to increase product stickiness by helping customers standardize and optimize AI workflows.</p>

<h2>Google Announces Gemini 4 Carbon</h2>
<a name="story-25716"><img src="https://wsrv.nl/?url=https%3A%2F%2Fstorage.googleapis.com%2Fgweb-uniblog-publish-prod%2Fimages%2Fgemini_4_carbon_exploitgym.width-1200.format-webp.webp&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Google has introduced Gemini 4 Carbon, a frontier model designed for advanced cybersecurity and long-horizon engineering tasks. The model ranks first on the Artificial Analysis Intelligence Index (v5.0) and demonstrates high performance in vulnerability detection, exploitation, and remediation across benchmarks such as SEC-bench Pro, ExploitGym, and CWE-bench.</p><p>The model is built to support sustained agentic workflows and features improvements in model alignment, output honesty, and resistance to prompt injection. Google is currently rolling out access to a subset of cyber defenders and trusted partners through the Fairwind Program ahead of a wider release.</p>

<h2>GitHub Debuts Copilot Fusion Model Selection and Orchestration System</h2>
<a name="story-25718"><img src="https://wsrv.nl/?url=https%3A%2F%2Fcdn.sanity.io%2Fimages%2F6vfeftx9%2Farticles%2F8280462c97c9b7ff22f4bcb528f4efd89934b50c-2152x2039.png%3Fw%3D1200%26auto%3Dformat&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>GitHub has launched GitHub Copilot Fusion, a runtime model router and orchestrator designed to automate model selection and execution patterns for coding tasks. Unveiled at the GitHub Universe conference, the system builds on Project HydraFusion and Copilot Auto Model Selection to handle reasoning, code generation, debugging, and tool use while allowing developers to choose from effort tiers like Standard, High, and Max.</p><p>According to GitHub benchmarks, the Fusion Max tier delivers benchmark performance comparable to Claude Code with Opus 5.5 Max at roughly half the API cost and in about 40% less time per task. Enterprise administrators can configure policy states, set default models, and restrict which underlying models Copilot Fusion can utilize across their development teams.</p>

<h2>Nvidia Releases Nemotron 3.5 Transcribe Open-Weight Speech Model</h2>
<a name="story-25703"><img src="https://wsrv.nl/?url=https%3A%2F%2Ftechcrunch.com%2Fwp-content%2Fuploads%2F2026%2F10%2FAI-on-the-tongue.png%3Fw%3D1024&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Nvidia has released Nemotron 3.5 Transcribe, a free, open-weight model designed to transcribe audio across 40 languages, alongside version 2 of its Granary speech dataset. The 30-billion-parameter model handles recordings up to an hour long, attributes speakers to up to eight individuals, and translates 31 languages to and from English.</p><p>Targeted at developers building business meeting and medical transcription applications, the model can run on local hardware such as edge controllers and laptops, as well as enterprise datacenter chips. The release coincides with a surge of competing AI voice tools from companies including Mistral, ElevenLabs, and Salesforce.</p>

<h2>Anthropic Study Finds Experts Frequently Defer to AI Agents in Judgment Calls</h2>
<a name="story-25667"><img src="https://wsrv.nl/?url=https%3A%2F%2Fwww.anthropic.com%2F_next%2Fimage%3Furl%3Dhttps%253A%252F%252Fwww-cdn.anthropic.com%252Fimages%252F4zrzovbb%252Fwebsite%252Fea6b9bd3ca8b59f150d912a3855fc1beaf9e7792-1920x926.png%26w%3D3840%26q%3D75&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Anthropic researchers conducted a randomized controlled trial involving 50 professional analysts performing a causal inference task using Claude Code to examine whether human experts maintain independent judgment when working with AI agents. By secretly introducing a randomized preference into each agent's instructions across four analytical decisions, the study measured how often experts adopted the agent's preferred option.</p><p>The results showed that analysts followed their agents' leans 86% of the time, frequently repeating the agents' arguments in post-task surveys while believing their final recommendations were entirely their own. Although analysts using AI completed tasks faster and made fewer methodological errors than those working without it, the findings highlight potential risks of unintentional human deference to hidden or arbitrary AI preferences in critical fields like safety research.</p>
<p><small>Links: <a href="https://www.anthropic.com/research/agents-judgment-calls">anthropic.com</a></small></p>

<h2>Survival LLM Offline Emergency Assistant Released</h2>
<a name="story-25658"><img src="https://wsrv.nl/?url=https%3A%2F%2Fwww.brangus.io%2Fsurvival-llm%2Fscreenshot.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Survival LLM is a free, open-source desktop application that pairs a local AI model with an offline reference library, allowing users to query emergency guidance, medical manuals, and Wikipedia articles without an internet connection. Operating entirely on the user's computer to ensure privacy, the app automatically selects an appropriately sized AI model based on available hardware memory and cites exact source passages for every generated response.</p><p>The system includes extensive reference materials ranging from FEMA and CDC guidelines to survival manuals, repair guides, and medical encyclopedias, requiring initial setup while online to download the necessary data and engine components. Users can also supplement the local database with personal files like PDFs and notes, and the software supports configurable reasoning tokens and local memory tracking for customized offline assistance.</p>
<p><small>Links: <a href="https://www.brangus.io/survival-llm">brangus.io</a> | <a href="https://news.ycombinator.com/item?id=50264853">hacker news</a></small></p>

<a name="story-25577"><img src="https://wsrv.nl/?url=https%3A%2F%2Fplatform.theverge.com%2Fwp-content%2Fuploads%2Fsites%2F2%2F2026%2F10%2FApple-Creator-Studio-intelligent-assistant-in-Keynote-on-MacBook-Pro-261027_big.jpg.large_2x.jpg%3Fquality%3D90%26strip%3Dall%26crop%3D0%2C0%2C100%2C100&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
