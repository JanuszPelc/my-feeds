<h2>Llama-Modchip v2.4.0 Released for Running Large Models on Consumer CPUs</h2>
<a name="story-26829"><img src="https://wsrv.nl/?url=https%3A%2F%2Fpbs.twimg.com%2Fmedia%2FHGpEAoya8AAWLhu.jpg&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Llama-modchip v2.4.0 is an open-source utility designed to execute massive large language models, including the 284.33B DeepSeek-V4-Flash and 30B mixture-of-experts models, entirely on consumer-grade CPUs with zero GPUs required. By implementing analytical second-order Hessian compression, Fractal-64 tensor transcoding, and advanced memory tiling, the project reduces the DeepSeek model footprint to fit within 64 GB of RAM while preserving extended context windows.</p><p>The toolkit delivers notable inference speeds across different hardware setups, achieving up to 14.7 tokens per second for DeepSeek-V4-Flash on standard 64GB desktop systems and over 100 tokens per second for smaller MoE models on multi-channel workstations. Furthermore, it incorporates a low-latency warm-restore feature for coding assistants like Claude Code, removing prompt re-evaluation bottlenecks to streamline local agent workflows.</p>
<p>Nov 8 · <a href="https://github.com/synchopate/llama-modchip">github.com</a> | <a href="https://news.ycombinator.com/item?id=50411961">hacker news</a></p>
