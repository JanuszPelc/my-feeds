<h2>Netmeister Discusses Unsustainable Pressures on Cybersecurity Defense Teams</h2>
<a name="story-25660"><img src="https://wsrv.nl/?url=https%3A%2F%2Fwww.techwyse.com%2Fwp-content%2Fuploads%2F2026%2F04%2FUntitled-design-5.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Cybersecurity commentator Jan Schaumann argues that current vulnerability management practices are facing an unsustainable deluge of zero-days, broken disclosures, and AI-generated security reports that function as a distributed denial-of-service attack on defenders. With multiple severe vulnerabilities hitting simultaneously, organizations lack the staffing, tooling, and time required to assess attack surfaces and deploy fixes effectively.</p><p>The piece highlights recent high-profile incidents—including virtualization escapes, TLS trust issues, and widespread parser flaws—to illustrate that developing a patch is rarely the primary bottleneck. Instead, defenders are overwhelmed by context switching, sensationalized marketing hype, and low-quality automated reports, leaving limiting blast radius and assuming compromise as the primary viable strategies.</p>

<h2>Anthropic Expands GSA Partnership to Offer Discounted Claude Services to Government Agencies</h2>
<a name="story-25634"><img src="https://wsrv.nl/?url=https%3A%2F%2Ftechcrunch.com%2Fwp-content%2Fuploads%2F2026%2F07%2Fanthropic-claude-india-pricing-tiers.jpg%3Fresize%3D800&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Anthropic is expanding its partnership with the General Services Administration (GSA) to provide a 40% discount on Claude Enterprise, Claude for Government, and the Claude API to federal, state, local, tribal, and territorial governments. Anthropic is also launching a program to assist government agencies with implementation and best practices.</p><p>The agreement, which utilizes consumption-based billing without minimum spend requirements, is estimated to save the government $1 billion. Approximately 500 government organizations currently use Claude, with federal civilian agency usage having increased twenty-fold over the past year. While Claude for Government is available with FedRAMP High authorization, Claude Enterprise is currently in the process of obtaining FedRAMP Moderate authorization.</p>

<h2>Go Security Team Details Response to eMudhra Key Disclosure Incident</h2>
<a name="story-25571"><img src="https://wsrv.nl/?url=https%3A%2F%2Fqaserver-int.emudhra.net%3A18006%2FPaperlessDSC%2Fimages%2Fkc_images%2FKC20-6.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Following the discovery that eight eMudhra-issued intermediate certificates relied on trivially weak private keys, the Go Security team utilized its urgent track for the first time to issue patched minor releases. Developers using Go network services are advised to upgrade to versions 1.27.3 or 1.26.10 and verify binaries using tools like govulncheck.</p>

<h2>Microsoft Patches High-Severity Flaw in Authenticator for Android</h2>
<a name="story-25535"><img src="https://wsrv.nl/?url=https%3A%2F%2Fwww.windowslatest.com%2Fwp-content%2Fuploads%2F2026%2F06%2FMS-Authenticator-Root-and-jailbreak-warning.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Microsoft has patched a high-severity local elevation-of-privilege vulnerability (CVE-2026-80097) in the Microsoft Authenticator app for Android. Discovered by Enclave researchers, the flaw allowed malicious local applications with no declared permissions to spoof trusted Microsoft apps and request delegated account access tokens without user interaction.</p><p>The vulnerability stemmed from improper authentication within the app's broker component, specifically an exported Android activity that failed to verify whether the calling application matched the claimed identity in the request. By passing signature checks associated with legitimately installed apps like Microsoft Teams, unauthorized applications could access sensitive resources including mailboxes, OneDrive files, and SharePoint content. Microsoft addressed the flaw in Authenticator version 6.2606.4246.</p>

<h2>Evan Czaplicki Examines the Technical and Operational Costs of Sending Email</h2>
<a name="story-25474"><img src="https://wsrv.nl/?url=https%3A%2F%2Fcdn.prod.website-files.com%2F645258dee17c72222bca47d8%2F65f451b5c137d8d233e35c9c_48a19fc2-ee7f-456c-bf9e-9093b76b1023.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Former Google engineer and Elm creator Evan Czaplicki explores why third-party services charge high fees to send emails, investigating whether the underlying technical process justifies the expense. After successfully writing custom Haskell code to send emails via SMTP, he discovered that the primary challenges lie outside basic protocol implementation.</p><p>While technical hurdles like setting up DNS records and TLS are manageable, delivering messages reliably across all major providers requires navigating complex, opaque spam filters and IP address block blacklists. Because some inbox providers penalize entire IP blocks based on third-party spam activity, senders must often acquire dedicated infrastructure and high-volume sending profiles, which explains the real-world costs of email delivery.</p>

<h2>IETF Draft Defines MoLE Protocols for Unlinkable Endorsements</h2>
<a name="story-25443"><img src="https://wsrv.nl/?url=https%3A%2F%2Fpbs.twimg.com%2Fmedia%2FFKpZVKSXsAAB7nk.jpg&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>An Internet-Draft authored by contributors from Google, Mozilla, and Cloudflare outlines the protocols that instantiate the Moderation of unLinkable Endorsements (MoLE) architecture. The specification details two endorsement protocols—Issuer-Hiding Anonymous Token (IHAT) and Longfellow—which enable clients to prove they hold a trusted endorsement without revealing the specific anchor.</p><p>Additionally, the document defines three credential protocols: Anonymous Credit Tokens (ACT), Privacy Pass with a Reverse Flow, and Budget Privacy Pass. These mechanisms allow moderators to issue, verify, and update per-client state while preventing presentation linkage, alongside provisions for key rotation, discovery, and security considerations.</p>
<p><small>Links: <a href="https://datatracker.ietf.org/doc/draft-jms-mole-protocols/">datatracker.ietf.org</a> | <a href="https://lobste.rs/s/xj200h/mole_protocols">discussion</a></small></p>

<h2>Apple Details Automatic Blocking of Compromised eMudhra Certificates</h2>
<a name="story-25437"><img src="https://wsrv.nl/?url=https%3A%2F%2Fministryofcyberaffairs.com%2F_next%2Fimage%3Furl%3Dhttps%3A%2F%2Fstorage.googleapis.com%2Fcybersentry-news-images%2Farticles%2Fresearch%2F1792605858915-aihero.jpg%26w%3D3840%26q%3D75&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Apple has begun automatically blocking twelve compromised intermediate Certification Authority certificates issued by eMudhra across Safari, Mail, and system networking frameworks. The security measures follow the compromise of private keys across eight eMudhra intermediate CAs, which left them vulnerable to unauthorized TLS certificate generation and potential impersonation attacks.</p><p>While standard Apple applications handle the block automatically via background updates, command-line tools on macOS like curl and git that check against the system's /etc/ssl/cert.pem file may still accept the certificates until a future software update is released. Apple has provided manual Terminal commands for system administrators and developers who need to immediately remove the affected root certificates from their local configuration files.</p>
<p><small>Links: <a href="https://support.apple.com/en-us/149555">support.apple.com</a> | <a href="https://lobste.rs/s/xzp4m0/about_compromised_emudhra_intermediate">discussion</a></small></p>
