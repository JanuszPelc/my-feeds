<h2>Alpine Linux Rebuilds GitLab Instance After Attempted Exploitation of CVE-2026-97229</h2>
<a name="story-25779"><img src="https://wsrv.nl/?url=https%3A%2F%2Fmedia.licdn.com%2Fdms%2Fimage%2Fv2%2FD5612AQGy9yfXEtKg1w%2Farticle-cover_image-shrink_720_1280%2FB56Zk0ZU_FKAAI-%2F0%2F1757520681324%3Fe%3D2147483647%26v%3Dbeta%26t%3DlQ7YOInOtNyqwaCwrbINWZLWKj9ALJ9DKZGO3KPpTKk&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Alpine Linux rebuilt its hosted GitLab instance from scratch following an attempted exploitation of the critical CVE-2026-97229 vulnerability on October 20 and 21, 2026. While no evidence was found that the attacker successfully executed code or tampered with Alpine packages, releases, or the `aports` repository, the team treated the instance as compromised as a precautionary measure.</p><p>The vulnerability is a CVSS 10.0 flaw in how the Ruby engine evaluates regular expressions. The incident occurred because the GitLab instance was running a version that had not yet been patched with the required Ruby updates. Users are advised to reset their GitLab passwords and ensure they are using Ruby versions 3.3.13, 3.4.12, 4.0.9, or later, or the latest `alpinelinux/gitlab` container images.</p>

<h2>Orange Tsai Achieves Microsoft Edge Sandbox Escape via Logic Bugs</h2>

<p>Orange Tsai of DEVCORE Research Team achieved a Microsoft Edge sandbox escape at Pwn2Own Berlin 2026 by chaining four logic bugs. <h2>Gareth Heyes Details Bypasses for Popular SVG Sanitizers</h2>
<a name="story-25726"><img src="https://wsrv.nl/?url=https%3A%2F%2Fblog.nintechnet.com%2Fwp-content%2Fuploads%2F2020%2F05%2Felementor-svg-xss-protection-bypass.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>PortSwigger researcher Gareth Heyes has published findings detailing bypasses for six out of eight popular SVG sanitizers. The research demonstrates various exploitation vectors, including namespace confusion, animate tags, self-contained XSLT stylesheets, and response headers capable of executing JavaScript in Firefox even when the response body contains harmless XML.</p><p>Additional findings reveal that Safari can import image formats such as GIFs as SVG files to execute JavaScript through a use element, successfully bypassing multiple libraries. While sanitizers like DOMPurify and darylldoyle/svg-sanitizer resisted the tested techniques, the vulnerabilities illustrate the persistent difficulties involved in safely handling complex vector graphics formats.</p>

<h2>Critical Code-Execution Vulnerability Discovered in TianoCore EDK II UEFI Firmware</h2>
<a name="story-25702"><img src="https://wsrv.nl/?url=https%3A%2F%2Feclypsium.com%2Fwp-content%2Fuploads%2Fhydrophobia-screen-4.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>A critical memory-corruption vulnerability, tracked as CVE-2026-97631, affects the TianoCore EDK II open-source codebase widely used by hardware vendors to create UEFI boot firmware for servers. Discovered by security researchers and prematurely exposed through a public code repository pull request, the 9.5-severity flaw resides in the PXE Base Code driver's handling of ICMP error messages.</p><p>An attacker with low-level local network access can exploit the vulnerability during a network boot sequence to execute malicious code in ring 0 before operating system defenses and Secure Boot initialize. Because EDK2 reference code is utilized extensively across the server ecosystem, affected organizations must coordinate with firmware vendors to apply patches and temporarily disable unused network boot capabilities to mitigate potential compromise.</p>
