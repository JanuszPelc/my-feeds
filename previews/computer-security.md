<h2>IETF Draft Defines MoLE Protocols for Unlinkable Endorsements</h2>
<p>An Internet-Draft authored by contributors from Google, Mozilla, and Cloudflare outlines the protocols that instantiate the Moderation of unLinkable Endorsements (MoLE) architecture. The specification details two endorsement protocols—Issuer-Hiding Anonymous Token (IHAT) and Longfellow—which enable clients to prove they hold a trusted endorsement without revealing the specific anchor.</p><p>Additionally, the document defines three credential protocols: Anonymous Credit Tokens (ACT), Privacy Pass with a Reverse Flow, and Budget Privacy Pass. These mechanisms allow moderators to issue, verify, and update per-client state while preventing presentation linkage, alongside provisions for key rotation, discovery, and security considerations.</p>

<h2>Apple Details Automatic Blocking of Compromised eMudhra Certificates</h2>
<p>Apple has begun automatically blocking twelve compromised intermediate Certification Authority certificates issued by eMudhra across Safari, Mail, and system networking frameworks. The security measures follow the compromise of private keys across eight eMudhra intermediate CAs, which left them vulnerable to unauthorized TLS certificate generation and potential impersonation attacks.</p><p>While standard Apple applications handle the block automatically via background updates, command-line tools on macOS like curl and git that check against the system's /etc/ssl/cert.pem file may still accept the certificates until a future software update is released. Apple has provided manual Terminal commands for system administrators and developers who need to immediately remove the affected root certificates from their local configuration files.</p>

<h2>Security Risks of the POSIX wordexp(3) Function Examined</h2>
<p>The POSIX wordexp(3) C API, commonly recommended for shell-style expansions such as tilde expansion, presents significant security risks when handling untrusted inputs because it enables command expansion by default. Developers must explicitly pass the WRDE_NOCMD flag to disable this behavior, though this mitigation is frequently insufficient.</p><p>Various libc implementations, including musl and macOS libc, delegate expansion directly to the underlying system shell after performing perfunctory scanning. Bypasses in these implementations demonstrate that they can fail to catch valid command substitution patterns, making wordexp(3) unsafe for processing untrusted data.</p>

<h2>Bitflux Compares DiskArray and AVL Tree Performance in Memory Is Slow, Disk Is Fast Part 3</h2>
<p>In the third installment of its performance analysis series, Bitflux challenges traditional computer science assumptions by demonstrating that a disk-based data structure, DiskArray, can outperform an in-RAM AVL binary tree at scale. Running on a 24-core Xeon server with NVMe drives, the analysis compares sorted arrays, linked lists, AVL trees, and DiskArray across search, retrieval, insertion, and deletion operations.</p><p>While an AVL tree holds a performance advantage when data fits within CPU cache limits, DiskArray scales significantly better once data moves into main memory, eventually surpassing the in-RAM tree at 16 million nodes and continuing up to 64 billion nodes before the AVL tree runs out of RAM. The breakdown examines how contiguous data layouts and optimized disk block transfers allow DiskArray to efficiently handle heavy workloads despite moving more raw bytes overall.</p>

<h2>Brotli Decoder Vulnerability CVE-2026-111497 Affects Multiple HTTP Libraries and Applications</h2>
<p>A critical out-of-bounds write vulnerability in Google's Brotli compression library, tracked as CVE-2026-111497 with a CVSS score of 9.2, impacts a wide range of HTTP libraries, runtimes, and applications. Initially highlighted in Node.js under the name Node2Shell, the flaw allows unauthenticated remote attackers to corrupt memory, cause crashes, leak sensitive data, or execute arbitrary code via crafted Brotli-compressed data streams.</p><p>Subsequent disclosures revealed that the vulnerability extends across multiple ecosystems, including Python packages such as Brotli and brotlicffi, C++, Envoy, Istio, and Bun. Affected organizations and developers are advised to apply security patches—such as upgrading to Brotli 1.2.1 or runtime-specific fixed versions—or temporarily disable Brotli decoding in incoming and outbound HTTP traffic to mitigate exposure.</p>
