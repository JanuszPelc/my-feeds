<h2>Daniel Kochmański Details Improvements to Number Hashing and Hash Tables in ECL</h2>
<a name="story-25579"><img src="https://wsrv.nl/?url=https%3A%2F%2Fturtleware.eu%2Fposts%2Fsxhash-equalp-files%2Fcherry-picking.png&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Daniel Kochmański details the redesign of hash tables, hash functions, and number hashing under the EQUALP predicate in Embeddable Common-Lisp (ECL). The post outlines the challenges of consistent numeric hashing across the Common Lisp numeric tower, where mathematically equivalent numbers across different representations must produce identical hash values.</p><p>The optimization journey progresses from a simple baseline using lossy float conversions to a refined intermediate design, and finally to a compact dyadic rational tuple representation scheme. This evolution eliminates unnecessary object allocation, avoids precision loss for large floats and ratios, significantly reduces hash collisions, and yields dramatic performance gains in benchmark comparisons against other Common Lisp implementations.</p>

<h2>Microsoft Details Type Server Protocol Specification for Python Analysis</h2>
<p>Microsoft has published the specification for the Type Server Protocol (TSP), a JSON-RPC protocol designed to handle Python analysis data and workspace type-analysis state. The protocol extends Language Server Protocol conventions, providing standardized mechanisms for version negotiation, snapshot management, import resolution, and fine-grained type queries.</p><p>The protocol features a connection model supporting an optional multi-connection mode for concurrent read-only tasks over IPC channels, alongside strict snapshot-bound type results and position conventions. Version history tracks incremental updates to request types and transport negotiation, establishing a structured interface for integrating type checkers into development environments.</p>
<p><small>Links: <a href="https://github.com/microsoft/pylance-release/blob/main/docs/tsp/type-server-protocol.md">github.com</a> | <a href="https://news.ycombinator.com/item?id=50248371">hacker news</a></small></p>

Consequently, development on the project has ended in the main repository, leaving its future entirely dependent on whether external contributors decide to pick it up elsewhere.</p>

<h2>Ben Joffe Proposes Faster Algorithm for Signed 64-Bit Floor Division by Constants</h2>
<a name="story-25523"><img src="https://wsrv.nl/?url=https%3A%2F%2Ffiles.speakerdeck.com%2Fpresentations%2Fe5e4570c4b8c40f093f468b39b115334%2Fslide_1.jpg&amp;w=1200&amp;h=1200&amp;fit=inside&amp;we&amp;output=jpg&amp;bg=white" width="30%" align="right" /></a>
<p>Software engineer Ben Joffe has introduced a new approach for computing signed integer floor division by compile-time constants, yielding a 10 to 20 percent improvement in throughput on ARM processors and a 5 to 10 percent gain for most positive divisors on x86 architectures. The technique addresses limitations in mainstream programming languages and compilers that either lack native floor division or rely on slower algorithms.</p><p>While standard division rounds toward zero, floor division rounds toward negative infinity, a preferred behavior for applications tracking repeating patterns like timestamps and spatial coordinates. Historical references like Hacker's Delight previously highlighted the difficulty of optimizing constant floor division, and various software libraries have suffered bugs when attempting custom implementations. Joffe's blog post details the performance benchmarks, provides copy-and-pasteable function builders across multiple bit-widths, and supplies a reference C++ template.</p>

<h2>PaperPilot Open-Source Local PDF and Document Toolkit Released in Rust</h2>
<p>PaperPilot is a privacy-focused PDF and document toolkit written in pure Rust that operates entirely locally without cloud calls. Designed for both human workflows and AI coding agents, the engine provides document manipulation tools—including merging, splitting, compression, and OCR—across a command-line interface, a Model Context Protocol (MCP) server, a local REST API, and a browser-based WebAssembly version.</p><p>The project shares a unified Rust core across its various surfaces to ensure consistent performance while keeping files on the user's machine. Available under an Apache 2.0 license, PaperPilot currently supports tasks like page reordering, watermarking, and signature validation, with upcoming updates planned to introduce broad format conversions for Markdown, HTML, and Microsoft Office files.</p>
