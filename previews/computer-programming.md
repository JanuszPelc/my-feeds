<h2>WHIP Protocol Enables High-Quality Screensharing via OBS and FFmpeg</h2>
<p>The WebRTC-HTTP Ingestion Protocol (WHIP) allows users to stream video directly from OBS and FFmpeg into video conferencing applications. This method provides manual control over resolution, frame rate, bitrate, and codecs, bypassing the automated encoding limitations of browser-based screensharing.</p><p>This approach enables users to optimize streams for specific hardware and network conditions. By adopting these open standards, users can avoid the blurry video quality common to many proprietary conferencing clients.</p>

<h2>EPA Plans to Decommission Online Web Archive</h2>
<p>The Environmental Protection Agency (EPA) intends to decommission its online web archive by the end of 2026, removing tens of thousands of environmental reports, policy changes, and regulatory actions from the web. The repository contains at least 20 years of historical data used for research and public oversight.</p><p>Environmental advocates and historians warn that losing the archive will eliminate an irreplaceable resource. While the agency has previously attempted to discontinue the service before reversing course following public backlash, critics argue that decommissioning the site will make historical records more difficult to access and increase the workload for the agency's Freedom of Information Act (FOIA) office.</p>

<h2>Oldest GUI Application Compatible With Windows 11 Investigated</h2>
<p>An investigation into the oldest graphical user interface application that can run natively on Windows 11 without modification or emulation reveals that early 32-bit Windows NT binaries remain functional. Although Windows 11 lacks 16-bit NTVDM support, programs like FREECELL.EXE from February 1993 execute successfully out of the box.</p><p>Deeper exploration into early Windows NT pre-release builds identifies even older software, including CDPLAYER.EXE from November 1992, which bypasses crashes by utilizing the system's legacy crtdll.dll and an emulated CD-ROM driver. Furthermore, employing compatibility layers such as otvdm enables 16-bit applications like REVERSI.EXE from November 1985 to run on the modern operating system.</p>
<p><small>Links: <a href="https://blog.enlyth.com/posts/oldest-windows-gui-app-win-11/">blog.enlyth.com</a> | <a href="https://lobste.rs/s/rwubks/oldest_gui_application_still_runs_on">discussion</a> | <a href="https://news.ycombinator.com/item?id=50248055">hacker news</a></small></p>

<h2>Ben Joffe Proposes Faster Algorithm for Signed 64-Bit Floor Division by Constants</h2>
<p>Software engineer Ben Joffe has introduced a new approach for computing signed integer floor division by compile-time constants, yielding a 10 to 20 percent improvement in throughput on ARM processors and a 5 to 10 percent gain for most positive divisors on x86 architectures. The technique addresses limitations in mainstream programming languages and compilers that either lack native floor division or rely on slower algorithms.</p><p>While standard division rounds toward zero, floor division rounds toward negative infinity, a preferred behavior for applications tracking repeating patterns like timestamps and spatial coordinates. Historical references like Hacker's Delight previously highlighted the difficulty of optimizing constant floor division, and various software libraries have suffered bugs when attempting custom implementations. Joffe's blog post details the performance benchmarks, provides copy-and-pasteable function builders across multiple bit-widths, and supplies a reference C++ template.</p>
<p><small>Links: <a href="https://www.benjoffe.com/fast-floordiv">benjoffe.com</a> | <a href="https://lobste.rs/s/o5to4p/faster_way_compute_signed_64_bit_floor">discussion</a></small></p>

<h2>Stalwart Labs Releases Stalwart v1.0 Mail Server</h2>
<p>Stalwart Labs has released Stalwart v1.0, marking the first stable version of its open-source Rust-based mail and collaboration server after five years of development. The release focuses on high performance and database schema stability, featuring rewritten parsers utilizing SIMD and SWAR optimizations, optimized database backends, and a completely redesigned full-text search engine.</p><p>In benchmark comparisons against Postfix and Dovecot on identical hardware, Stalwart outperformed the traditional mail stack in 35 of 38 categories, including significantly faster IMAP operations, higher inbound SMTP throughput, and reduced message delivery latency. Version 1.0 also introduces support for document text extraction, post-quantum DKIM2 signatures, JMAP object metadata, and an enterprise AI-powered spam classifier.</p>

<h2>PaperPilot Open-Source Local PDF and Document Toolkit Released in Rust</h2>
<p>PaperPilot is a privacy-focused PDF and document toolkit written in pure Rust that operates entirely locally without cloud calls. Designed for both human workflows and AI coding agents, the engine provides document manipulation tools—including merging, splitting, compression, and OCR—across a command-line interface, a Model Context Protocol (MCP) server, a local REST API, and a browser-based WebAssembly version.</p><p>The project shares a unified Rust core across its various surfaces to ensure consistent performance while keeping files on the user's machine. Available under an Apache 2.0 license, PaperPilot currently supports tasks like page reordering, watermarking, and signature validation, with upcoming updates planned to introduce broad format conversions for Markdown, HTML, and Microsoft Office files.</p>

<h2>Keybytes Modular Keyboard Project Introduced</h2>
<p>Keybytes is an open-source, fully modular mechanical keyboard project where every individual key functions as its own rearrangeable 1u printed circuit board. Developed by NotARoomba, the system allows keys to be linked together in arbitrary configurations using magnetic cases and pogo pins on all four sides for power and I2C communication.</p><p>Each key module incorporates a CH32V003 RISC-V microcontroller to process inputs, while a central two-layer main board features an STM32WB55RGV6 microcontroller supporting Bluetooth and USB connectivity. The hardware also includes battery charging circuitry, a buck-boost converter, and 2MB of QSPI flash storage, with all design files, schematics, and CAD models published on GitHub.</p>
<p><small>Links: <a href="https://github.com/notaroomba/keybytes">github.com</a> | <a href="https://news.ycombinator.com/item?id=50228115">hacker news</a></small></p>

<h2>Arthur O’Dwyer Examines Fixits and Suppression Mechanisms in Compiler Warnings</h2>
<p>Arthur O’Dwyer explores two peripheral aspects of compiler diagnostic design: machine-readable fixits that prescribe treatments and suppression mechanisms used to silence warnings. He analyzes how compilers navigate the tension between changing code behavior to match likely programmer intent and preserving existing behavior.</p><p>O’Dwyer highlights that while some compilers offer both treatment and suppression options for ambiguous constructs, they often struggle with distinguishing typographical errors from deliberate code. He argues that diagnostic warning systems should employ relative rules evaluating the degree of syntactic ornamentation rather than absolute rules based on isolated patterns.</p>
